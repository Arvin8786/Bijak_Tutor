# BijakLearn Junior / Bijak Tutor

A child-friendly Malaysian primary-school learning PWA, designed for **understanding before progression**.

## Product principles
- Current applicable KSSR Semakan curriculum first, with versioned mappings for future curriculum updates.
- SK, SJKC and SJKT pathways; primary (Tahun 1–6) developed before secondary.
- Visual explanations, interactive mind maps, varied quizzes and misconception-guided reteaching.
- Mastery determined from multiple independent evidence items, not one multiple-choice answer.
- Parent-linked student accounts and evidence-based progress reports.
- Paid Premium and manually approved **Premium Kasih** receive identical learning features.
- **Google Sheets + Apps Script**, not Firebase; a secure API bridge remains a required deployment milestone.
- Open-weight/on-device models may assist teaching but cannot certify mastery.

## Status
This repository is being established as the **canonical project**. Earlier v6 ZIP materials are draft/pilot content and require controlled import, curriculum mapping checks and qualified review before production. Do not enroll real children or process financial documents before an end-to-end security assessment.

## Development
Feature work is proposed via branches and pull requests. See `docs/IMPLEMENTATION_PLAN.md` and `docs/SECURITY.md` in the setup branch.

## Data and secrets
Do **not** commit Google Sheets identifiers with sensitive access information, OAuth client secrets, student records, income evidence, payment screenshots or private API credentials.
